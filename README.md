# YojanaXpert AI

YojanaXpert AI is an intelligent government scheme recommendation platform that helps citizens discover welfare schemes they are eligible for. The system analyzes user information such as age, income, occupation, gender, location, and social category to provide personalized scheme recommendations.

The platform aims to simplify access to government benefits by combining Artificial Intelligence, Machine Learning, Voice Assistance, Fraud Detection, and User-Friendly Interfaces into a single solution.

---

# Problem Statement

Thousands of government welfare schemes are available across different sectors such as education, healthcare, agriculture, employment, housing, and social welfare. However, citizens often face difficulties in finding relevant schemes due to:

- Lack of awareness
- Complex eligibility criteria
- Scattered information across multiple portals
- Language barriers
- Risk of fraud and scam messages

YojanaXpert AI addresses these challenges by providing a centralized and intelligent recommendation system.

---

# Key Features

## Smart Scheme Recommendation
- Recommends schemes based on user eligibility.
- Supports both Central and State Government schemes.
- Displays scheme benefits, eligibility criteria, and application details.

## Voice-Based Input
- Enables users to provide information through voice commands.
- Improves accessibility for rural and non-technical users.

## AI Chatbot Assistant
- Assists users with scheme-related questions.
- Provides real-time guidance throughout the recommendation process.

## Family Dashboard
- Allows users to manage multiple family member profiles.
- Generates recommendations for the entire household.

## What-If Analysis
- Simulates profile changes such as age, income, and occupation.
- Helps users understand how eligibility changes over time.

## Fraud Detection System
- Detects fraudulent SMS messages.
- Identifies suspicious URLs and websites.
- Verifies phone numbers to reduce scam risks.

## Multilingual Support
- Supports multiple languages for better accessibility.

# Workflow

1. User enters profile information manually or through voice input.
2. The system validates and processes the data.
3. Eligibility criteria are matched against available schemes.
4. Recommendation engine ranks suitable schemes.
5. Fraud detection module analyzes suspicious content.
6. Chatbot provides assistance when needed.
7. Results are displayed through the dashboard.
